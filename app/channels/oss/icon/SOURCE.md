# Alefbet app icon

The glyph is the Hebrew letter alef (U+05D0) from the Secular One typeface, drawn as an outline
(filled at 48 px and below, where a stroke would vanish) on a near-black squircle.

- Background `#0B0F1A`, stroke `#7CC4FF`, stroke width 2.73% of the canvas, glyph height 66%.

  The license text is in `OFL-SecularOne.txt` next to this file. Only rasterised outlines of one
  glyph are used here; no font software is redistributed.
